# Gramedia Sales Performance Dashboard

Dashboard Analisis Performa Penjualan Gramedia (Studi Kasus Karawang & Purwakarta). Menganalisis total penjualan sebesar Rp64.340.000, tren harian, dan insight kategori buku.

## 📌 Objektif Proyek
Menganalisis tren penjualan harian dan kontribusi kategori buku untuk memahami perilaku konsumen dan memberikan rekomendasi strategi persediaan barang (supply), khususnya pada hari libur.

## 🛠️ Tools
* **Microsoft Excel:** Pembersihan data (Data Cleaning), pengolahan data analitik, dan pembuatan visualisasi *dashboard* interaktif.

## 💡 Insight Utama
1. **Puncak Penjualan:** Penjualan tertinggi secara signifikan terjadi pada hari libur (tanggal 24 & 25).
2. **Kategori Dominan (Best Seller):** Kategori buku *Self Improvement* menyumbang kontribusi terbesar (+26%) diikuti oleh buku *Fiksi* (+25%). Di sisi lain, alat tulis menjadi kategori dengan performa paling rendah (*Flop*).
3. **Rekomendasi Bisnis:** Perusahaan perlu menguatkan *supply* (stok) untuk buku-buku bergenre *Self Improvement* dan *Fiksi* menjelang akhir pekan/hari libur untuk memaksimalkan potensi pendapatan dari pelanggan usia remaja menuju dewasa.
